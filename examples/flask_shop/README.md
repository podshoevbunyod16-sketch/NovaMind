# Демо-магазин на Flask

Готовый пример интернет-магазина: его проверяют тесты (`tests/test_flask_shop.py`,
`tests/test_agent_builds_shop.py`) и его же собирает агент NovaMind, когда вы
просите «создай интернет-магазин на Flask».

## Запуск

```bash
pip install flask
python3 app.py            # http://127.0.0.1:8000
```

Переменные окружения:

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PORT` | `8000` | порт |
| `HOST` | `127.0.0.1` | адрес (для доступа с телефона в сети — `0.0.0.0`) |
| `SHOP_DB` | `data/shop.db` | файл базы SQLite |
| `SHOP_ADMIN_PASSWORD` | `admin` | пароль админки |
| `SHOP_SECRET` | `dev-secret-change-me` | ключ сессий — поменяйте на своё значение |

Демо-товары создаются при первом запуске. Админка — `/admin/login`.

## Что есть

* каталог с категориями и поиском (`/`, `/?category=посуда`, `/?q=кофе`);
* карточка товара (`/product/<id>`);
* корзина в сессии: добавить, изменить количество, удалить (`/cart`);
* оформление заказа с проверкой полей (`/checkout`) и страница заказа (`/order/<id>`);
* админка с паролем: добавление и удаление товаров, список заказов (`/admin`);
* `GET /healthz` — состояние и число товаров.

Зависимостей, кроме Flask, нет: база — стандартный `sqlite3`, шаблоны — Jinja2
из Flask.

## Структура

```
app.py                  всё приложение: маршруты, база, корзина, заказы
templates/base.html     каркас и стили
templates/*.html        каталог, товар, корзина, оформление, заказ, админка
data/shop.db            база (создаётся при запуске, в git не попадает)
```

## Проверка без запуска сервера

```bash
python3 -c "from app import app; c = app.test_client(); print(c.get('/').status_code)"
```

Так же проверяет агент: сервер в песочнице запускать нельзя — он занимает
терминал до таймаута, а `test_client` отвечает сразу.
