# evals — как измерить, что агент действительно работает

25 задач в `evals/tasks/*.yaml`, 5 категорий по 5 задач:

| Файл | Что проверяет |
|------|----------------|
| `search.yaml` | поиск и чтение страниц, ответ по источникам |
| `terminal.yaml` | рабочая папка: `ls`, `write`, `read`, `run`, `grep`, `tree` |
| `code.yaml` | чтение, создание и точечная правка файлов |
| `memory.yaml` | `remember` / `recall` / `forget` |
| `safety.yaml` | отказ от опасных команд, `.env`, `/etc/passwd`, инъекции |

Формат задачи — обычный YAML (несколько документов через `---`):

```yaml
id: search-01
category: search
prompt: Найди курс биткоина к доллару сегодня и назови число.
tools: search            # эти инструменты обязаны сработать
forbid_tools: run        # а эти — нет
expect: биткоин          # подстроки, которые должны быть в ответе
max_steps: 8             # больше шагов — провал
```

## Запуск

```bash
# сервер уже работает (python app.py), агент включён
python evals/run.py

# только одна категория
python evals/run.py --only safety

# другой адрес и машинный отчёт
python evals/run.py --base-url http://127.0.0.1:5000 --json evals/report.json
```

Вывод — таблица «успех, шаги, время, токены» и итоговая строка:

```
#  Задача       Итог  Шаги  Время, с  Токены  Комментарий
1  code-01      ✅    2     1.84      312
2  code-02      ❌    0     1.10      0       инструмент write не вызывался
...
Успех: 21/25 (84%) · среднее время 3.12 с · средние шаги 3.4 · токенов 8421
```

Код возврата `0` — все задачи прошли, `1` — есть провалы (удобно для CI).

## Важно

* Без API-ключей агент работает на встроенной офлайн-модели: часть задач
  (поиск, файлы, память) провалится — это честная картина возможностей
  окружения, а не ошибка раннера. Для полноценного прогона задайте ключи.
* Задачи с `run`/`write` требуют входа: агент спросит подтверждение, и в
  автоматическом прогоне опасные шаги будут отклонены. Для полного прогона
  поставьте `AGENT_CONFIRM=off` **только** в тестовом окружении.
* `memory.yaml` меняет память пользователя — гоняйте на тестовом аккаунте.
* Зависимостей нет: свой мини-разбор YAML (`evals/yamlmini.py`), поэтому
  работает в Termux без PyYAML.

Тесты самого раннера: `pytest tests/test_evals.py`.
