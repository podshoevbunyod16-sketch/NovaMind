# 🫧 Liquid Glass · NovaMind

Полное оформление интерфейса «живым стеклом» + живой поиск и рассуждения.

---

## 1. Что изменилось визуально

Единая дизайн-система в **`static/liquid-glass.css`** (подключается первой на всех
страницах), поверх неё — стилевые слои страниц:

| Страница | Файл |
|---|---|
| Чат | `static/style.css` |
| Настройки | `static/settings.css` |
| Вход / регистрация | инлайн-стили в `templates/auth.html` |
| Админ-панель | инлайн-стили в `templates/admin.html` |
| Composio | `templates/composio.html` |

Что входит в систему:

- **Живой фон** — три слоя: дрейфующие aurora-пятна (`body::before`), медленно
  вращающийся спекулярный блик (`body::after`), зерно + виньетка
  (`.lg-grain`, `.lg-vignette`).
- **Матовое стекло** — `backdrop-filter: blur() saturate()`, полупрозрачные
  градиенты, светящаяся кромка сверху (`--glass-inset`), мягкие тени.
- **4 темы** — `aurora`, `midnight`, `sunset`, `light`. Переключаются кнопкой
  🎭 (настройки), кнопкой-палитрой (чат) или точками на странице входа;
  выбор сохраняется в `localStorage` (`nova_theme`) и применяется везде.
- **Микроанимации** — пружинные нажатия кнопок, бегущий блик, всплывающие тосты,
  появление сообщений, «дыхание» логотипа и аватара.
- **Доступность** — `prefers-reduced-motion` и кнопка «✨ Анимации»
  (`data-motion="calm"`) отключают фоновую хореографию.
- **Fallback** — если браузер не поддерживает `backdrop-filter`, поверхности
  становятся плотными, интерфейс не ломается.

## 2. Поиск в интернете — как это выглядит

Кнопка **«Поиск в интернете»** в панели ввода. Сценарий в пузыре ИИ:

1. Пузырь появляется **пустым**.
2. Включается **анимированная сцена**: радарный луч, три орбиты с частицами,
   пульсирующее ядро, скан-линия, уходящая сетка.
3. Через полсекунды проявляется подпись **«Поищу в интернете»** и таймер.
4. Под сценой бегут **реальные шаги**: какой бэкенд пробовали, сколько
   результатов нашли, какие страницы читаем.
5. Найденные **источники** приходят отдельным событием и рисуются в пузыре.
6. С первым токеном ответа **сцена схлопывается** (анимация высоты и прозрачности).
7. Ответ **печатается по токенам**.
8. В самом **низу пузыря** остаётся блок «🔗 Источники · N» — сворачиваемый
   список с favicon, заголовком, доменом и ссылкой.
9. Под пузырем — мета (модель, время) и действия: копировать / озвучить / заново.

### События потока `POST /api/auto_search_stream`

Ответ — `application/x-ndjson`, по одному JSON-объекту на строку:

```jsonc
{"type":"stage","scene":"search","title":"Поищу в интернете","text":"…"}
{"type":"step","icon":"🌐","text":"Ищу через searxng…"}
{"type":"sources","sources":[{"title":"…","url":"https://…","host":"…"}]}
{"type":"stage","scene":"write","title":"Собираю ответ"}
{"type":"reasoning","token":"…"}          // ход мыслей, если включён
{"type":"token","token":"…"}              // печатающийся ответ
{"type":"result","searched":true,"sources":[…],"model":"…","trace":[…]}
{"type":"done","searched":true}
```

### Поисковые бэкенды

`apilayer → serper → searxng → ddg → ddg_lite → wiki` — перебираются до первой
непустой выдачи, по каждому остаётся запись в `trace` (время, ошибка).
Настраивается в `.env`:

```env
SEARCH_BACKENDS=searxng,ddg,ddg_lite,wiki
SEARXNG_INSTANCES=http://127.0.0.1:8888,https://searx.be
WIKI_API_BASES=https://ru.wikipedia.org/w/api.php
SEARCH_TIMEOUT=9
READER_TIMEOUT=14
```

Диагностика: **`GET /api/search/health?refresh=1`** (кеш 60 секунд) и панель
«Поиск в интернете» на странице настроек. Точка-индикатор рядом с кнопкой
поиска в чате показывает состояние бэкендов.

## 3. Рассуждения

Кнопка **«Рассуждение»**. В пузыре появляется сворачиваемая панель
«🧠 Рассуждение» с курсивным текстом хода мыслей; пока модель думает, панель
раскрыта, после ответа сворачивается.

- `gpt-oss-*` на Groq отдают нативный `reasoning` — он идёт в поток как есть.
- Для моделей без нативного reasoning выполняется короткий предварительный
  «план рассуждений», который печатается в ту же панель.
- Если модель ничего не отдала — панель честно сообщает об этом.

## 4. Единый слой ИИ и офлайн-модель

`ai_providers.chat_completion()` / `chat_stream()` — одна точка входа для всех
провайдеров (Groq, Gemini, OpenRouter, Cerebras, OpenAI-compatible/llama.cpp,
Pollinations, офлайн-модель). Раньше каждый маршрут дёргал транспорт вручную,
из-за чего, например, поиск ломался на Gemini (в URL провайдера плейсхолдер
`{model}`).

**`local_llm.py`** — встроенная офлайн-модель `nova-local-1`:

- работает без интернета и без ключей, чат не остаётся без ответа;
- не ищет в сети и честно об этом пишет;
- выбирается автоматически, если ни один облачный провайдер не подключён;
- доступна в настройках как провайдер «Локальная демо-модель».

Состояние движка: **`GET /api/ai/status`** → провайдер, модель, `offline`,
состояние поиска. Показывается в топбаре чата.

## 5. Бонусы

- **Ctrl+K / ⌘K** — командная панель: режимы, переключатели, команды `/help`,
  погода, валюты, Википедия, код, изображения.
- **Стоп-генерации** — кнопка отправки превращается в «стоп», `Enter` во время
  генерации останавливает поток.
- **Действия под ответом** — копировать, озвучить (Web Speech), ответить заново.
- **Источники сохраняются в истории** — при возврате к диалогу ссылки и
  рассуждения отрисовываются снова.
- **Тосты вместо `alert`** — стеклянный стек уведомлений внизу экрана.
- **Индикатор состояния** — точка в топбаре: модель, офлайн-режим, поиск.
- **Офлайн/онлайн** — при восстановлении соединения статусы обновляются сами.
- **Горячие клавиши** — `Enter` отправить, `Shift+Enter` перенос, `Ctrl+B`
  сайдбар, `Esc` закрыть панель/модалку, `Ctrl+/` подсказка.

## 6. Как проверить

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt

# backend: поиск, единый слой ИИ, страницы (локальные mock-серверы, сеть не нужна)
python -m pytest tests/test_search_and_ai.py -q

# всё вместе
python -m pytest -q

# frontend: настоящий index.html + app.js в jsdom (48 проверок сценария поиска)
npm install jsdom
python app.py &                     # поднять сервер на :5000
node tests/frontend/smoke.mjs http://127.0.0.1:5000
```
